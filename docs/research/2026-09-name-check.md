# Name check: "Karya" (15 Sep 2026)

For P0.4 in `docs/11-commercial-readiness.md`. Based on web research; the official databases have not been searched yet. This is not legal advice.

## Bottom line: high risk

An Indian company already sells **all-in-one small-business SaaS under the name "Karya"**. It is the same word, the same country, the same kind of buyer and the same category. Adding a word ("Karya Ops", "Karya App") would probably still be confusingly similar.

**Recommendation:** choose a different product name before buying a domain, building a landing page or filing anything. The name is only used in the product so far, so renaming now is cheap.

Using a name gives prior-use rights in India even without a registered trademark, so karya.cloud is a problem either way.

## Before settling on any new name

1. Search IP India yourself at https://tmrsearch.ipindia.gov.in/tmrpublicsearch/ (it may ask for an OTP and a CAPTCHA).
   - **Wordmark** search, set to "Contains", in classes **9, 42 and 35**, one class at a time.
   - Then a **Phonetic** search in the same three classes, to catch spellings like Kaarya or Kariya.
   - Open "Show Details" on each hit and note status, owner, "used since" date and goods/services.
2. Search WIPO Global Brand Database (branddb.wipo.int) and Google / Play Store / App Store for the name plus "software", "app", "billing", "orders".
3. Check the `.in` and `.com` domains and Instagram / WhatsApp Business handles.
4. Before spending on branding, get a short clearance opinion from a trademark attorney.

## Naming brainstorm, 15 Sep 2026 (parked)

Two rounds of suggestions were rejected. The decision was to park naming and keep "Karya" internally until a name comes up. Record of what didn't work, so it isn't repeated:

- **Round 1 (rejected):** Parchi, Bayana, Baaki, Pakka, Chopdo, Taiyaar, Dhaaga, Taana, Haathse, Galla, Stallwise, Makerbook, Handled, Orderwala, Duely, Loopd. Reasons given: too desi / colloquial, too cute / craft-y, too descriptive, and they don't sound good.
- **Round 2 (rejected):** Kramo, Orvia, Ordiva, Settlo, Kivo, Tavio, Clasp, Keel, Plinth.
- **What is wanted:** a **modern / startup** feel, "creative but within limits". Not local slang, not tied to crafts, not a literal description.

**Next time:** start from the user's own ideas, or from 2–3 brand names they love, rather than generating lists cold. Screen only the names the user likes.

None of these names were screened for conflicts.
